Privacy policy

Effective 7 November 2026

Unblackboxed is a YouTube and Instagram channel of tech explainers. This policy covers this website and Unblackboxed Robot, the tool the channel uses to upload its own videos to YouTube.

Unblackboxed Robot

  • Who uses it. Unblackboxed Robot is a private tool. It isn't offered to the public, and only the channel's own Google account signs in to it.
  • YouTube API Services. The robot uses YouTube API Services with a single permission (youtube.upload). It uses that permission only to upload the channel's own videos and to set their titles, descriptions, tags, thumbnails and publish times.
  • What it collects. Nothing about viewers or anyone else. It doesn't read, collect, store, sell or share personal data.
  • What it stores. The sign-in token is kept as an encrypted secret in GitHub Actions and is used only to upload videos. The links of uploaded videos are kept in the channel's private GitHub repository.
  • Google and YouTube terms. Because the robot uses YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy also apply.
  • Removing access. The robot's access can be removed at any time on the Google security settings page: myaccount.google.com/permissions.

This website

This website has no sign-up, no cookies, no analytics and no ads. It's hosted on GitHub Pages. GitHub may log technical data such as IP addresses to run and protect the service, as described in the GitHub General Privacy Statement.
